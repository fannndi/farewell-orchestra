# Engineering Skills

Model-invoked skills for daily code work. Each skill maps to one of the 4 orchestra agents.

## Model-invoked

| Skill | Agent | Lines | Description |
|-------|-------|-------|-------------|
| [orchestrate](orchestrate/SKILL.md) | orchestrator | ~50 | Decomposition, fan-out, synthesis, delegation with budget awareness |
| [research-codebase](research-codebase/SKILL.md) | researcher | ~40 | Forensic investigation — file:line evidence, confidence levels, domain mapping |
| [audit-security](audit-security/SKILL.md) | reviewer | ~50 | STRIDE threat modeling, correctness checklist, severity classification |
| [implement-change](implement-change/SKILL.md) | executor | ~50 | YAGNI Ladder, precision standard, DoD gate, minimal viable change |
| [verify-profile](verify-profile/SKILL.md) | all | ~35 | 15-check config validation for all 4 profiles |
