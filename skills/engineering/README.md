# Engineering Skills

Model-invoked and user-invoked skills for daily code work. Each skill maps to one of the 4 orchestra agents.

## Model-invoked

| Skill | Agent | Lines | Description |
|-------|-------|-------|-------------|
| [orchestrate](orchestrate/SKILL.md) | orchestrator | ~60 | Decomposition, fan-out, synthesis, delegation with budget awareness |
| [research-codebase](research-codebase/SKILL.md) | researcher | ~50 | Forensic investigation — file:line evidence, confidence levels, domain mapping |
| [audit-security](audit-security/SKILL.md) | reviewer | ~65 | STRIDE threat modeling, correctness checklist, severity classification |
| [implement-change](implement-change/SKILL.md) | executor | ~90 | YAGNI Ladder, precision standard, DoD gate, minimal viable change |
| [verify-profile](verify-profile/SKILL.md) | all | ~50 | 15-check config validation for all 4 profiles |
| [full-cycle](full-cycle/SKILL.md) | orchestrator | ~50 | Complete pipeline — decompose, fan-out, implement, verify |
| [compound-review](compound-review/SKILL.md) | reviewer | ~45 | Multi-axis parallel review for changes >50 lines |

## User-invoked

| Skill | Agent | Lines | Description |
|-------|-------|-------|-------------|
| [ask-orchestrator](ask-orchestrator/SKILL.md) | user | ~45 | Router — maps all 14 skills and their chain relationships |
| [grill-boss](grill-boss/SKILL.md) | user | ~30 | Ambiguity resolution — one question, concrete options, max 3 rounds |
| [setup-orchestra](setup-orchestra/SKILL.md) | orchestrator | ~55 | Pre-flight validation of profiles, personas, skills, connectivity |
| [writing-orchestra-skills](writing-orchestra-skills/SKILL.md) | user | ~55 | Meta-skill — anatomy, invocation rules, quality gates, split criteria |
