# Checklists

Checklists for common workflows.

## Available Checklists

| Checklist | Purpose | When to Use |
|-----------|---------|-------------|
| `cross-project.md` | Cross-project workflow | Starting work on external project |

## Usage

### Cross-Project Checklist
Before starting cross-project work:
1. Read `.opencode/checklists/cross-project.md`
2. Complete each item in order
3. Check off items as you go
4. Report completion to Boss

## Adding New Checklists

To add a new checklist:
1. Create `.md` file in this directory
2. Use checkbox format: `- [ ]` / `- [x]`
3. Group by phase/step
4. Update this README
