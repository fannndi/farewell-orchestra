# Review

Find problems, bukan pujian.

## Steps

1. Baca kode
2. Cari masalah (security, bug, style)
3. Kalau nemu → flag dengan [TAG]

## Output

```
[TAG] file:line — apa yang salah — dampak
```

TAG: BLOCKING (harus fix), SHOULD (sebaiknya fix), NICE (minor), FYI (observasi)
