# Orchestrate

Coordinate researcher, reviewer, executor.

## Steps

1. Decompose task jadi bagian kecil
2. Dispatch researcher + reviewer (parallel)
3. Tunggu keduanya selesai
4. Synthesize findings
5. Brief executor
6. Verify output
7. Report ke Boss

## Output

```
[PROGRESS] apa yang dilakukan
[NEXT] apa yang akan dilakukan
```
